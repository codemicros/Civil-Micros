# AdSense setup for CivilMicros

The website already includes clearly separated advertisement areas after useful page content.

Before enabling live ads:
1. Replace the placeholder publisher value with your real AdSense publisher ID.
2. Add the AdSense site script to the shared page template/head.
3. Replace each visual `Advertisement Area` block with your approved ad unit code.
4. Update `ads.txt` with the exact publisher line from your AdSense account.
5. Keep the calculator and primary page content visible before advertisements.

No fake publisher ID is shipped in the production HTML.
