# CivilMicros

Static website project for civil.codemicros.com.

## Included
- Home page
- Category pages
- Working calculators
- Estimator pages
- Formula pages
- Guide pages
- Resource pages
- SVG logo and category icons
- robots.txt, sitemap.xml, CNAME

## Deploy on GitHub Pages
1. Upload all files to a GitHub repository.
2. Enable GitHub Pages from the repository settings.
3. Keep the included `CNAME` file for `civil.codemicros.com`.
4. Point your DNS CNAME record to the GitHub Pages hostname.

## AdSense setup
- The site includes clean ad placeholder areas.
- Replace placeholders with your own AdSense code only after your site is approved.
- Keep ads below the main content and avoid pushing the calculator below ads.
